## 1. The pattern, which is the most useful thing here

Across ~18 findings, the defects cluster hard:

> **This project's errors live in its prose, its wiring, and its provenance — and
> essentially never in its mathematics.**

The statistics were audited against closed forms and ground-truth simulation and came
back **sound** (F154): the paired bootstrap really pairs and is slightly conservative,
block length is *not* load-bearing (retiring a standing objection to the whole D6 arc),
the MDE constant is exact, `poisson_ci` is genuinely Garwood-exact to 2.66e-15. The one
defect found there was a *docstring* misdescribing a margin the code computes correctly.

Meanwhile: config knobs documented as active with zero readers (F145), a gate described
as the core innovation and wired into nothing (F26), a guarantee of "no divergent Sharpe
implementations" alongside two disjoint Sharpe stacks (F153), a decision citing no
document (F142), fixtures silently eaten by `.gitignore` (F144), figures propagating by
citation rather than recomputation (F146, F147).

**Consequence for anyone continuing: review effort is better spent on what the code is
*connected to* than on what it *computes*.** And a second, sharper rule that earned
itself three times over:

> **An invariant a repo cannot check is a belief.** Every false guarantee found here
> was one with no executable guard. The ones with tests were true.

## 3. What was fixed (all verified, all tested)

- **The poison cache** (`tools/data_cache.py`). A blocked fetch wrote a header-only CSV
  that every later run trusted *forever*, surviving restoration of network access.
  Now: never writes an unvalidated cache, detects an existing stub, writes atomically.
  Verified end-to-end — the lab exits 2 with an actionable message and **does not
  re-create the stub**, so the trap cannot re-arm.
- **The `.gitignore` root cause** (F144). `docs/research/data/` tracks 26 files, all
  JSON, zero CSV. The four fixtures weren't forgotten — a blanket `*.csv` ate them
  while their JSON sibling in the same commit survived. Added a scoped negation, plus
  a preflight reporting all missing fixtures at once with their declared SHA-256.
- **The blocked front door** (F156, *correcting my own F144*). The gap study's source
  audits never needed market data; `--selfcheck` just died before reaching them.
  **17 of 18 run in ~2s.** Added an `--audits` entrypoint.
- **CA-ANNOUNCE forecast time** (F152). Postdiction now rejected. The un-closeable half
  — hindsight in the *choice* of vantage — is reported instead, with an honest note
  that my own rank test (p=0.55) is **blind** to the pattern present.
- **The trader invariant** (F158, *approved*). `live/trader.py` refuses to start when
  `ACTIVE_MODE` and `LIVE_SYMBOL` disagree. Refuses rather than auto-corrects.
- **F155 partially repaired** (F159). Four absence flags now derive from source and
  **flip end-to-end** when the control is implemented — verified by shadow remediation.
- **CLAUDE.md §2/§3/§5/§10**, `docs/research/README.md`, and one drifted study doc
  corrected, with original text retained.
